# JevPilot 全链路优化与验证 · 2026-09-25

本轮覆盖 14 项能力的公共调用、缓存、预算和回退路径，实际修改工具选择、代码审查/测试选择、质量/翻译检查、上下文交接。Chrome/CUA 沿用上一轮已验收的导航入口。**不是每个模块都需要改代码，也没有把降低检查质量当作优化。**

基线：`b8189c063aab5b152127711103a30b071e2adcba`。本轮优化源码、可复现脚本和原始数据随本报告提交。没有付费 GPT 对照，不报告整项任务、省订阅额度或通用加速百分比。

## 已修复的浪费与正确性问题

1. **已确定的必选项仍收费判断。** 必用工具、必跑/已修改的测试，原先照样送给 Jev，然后无论建议如何都保留。现在直接按规则保留，只判断可选项。结果保持原顺序，规则结果明确标为 `source: policy`，不冒充 Jev 结果。
2. **独立检查串行等网络。** 风险初筛与测试筛选、内容规则与翻译核对可以并行。现在最多两个请求同时进行；每个分支的多批次仍串行。共享预算不够两次完整请求时保持串行，不提高预算、不使用新任务 ID 绕过限制。检查命令仍按原有顺序执行。
3. **消息移动造成重复判断。** 上下文交接以前把绝对消息位置混入缓存指纹。插入前置消息后，相同工具交换会再次付费判断。现在将位置检查与内容身份分开：位置仍保护最近消息，内容、交换内部顺序及调用方元数据保持在缓存键中。
4. **旧压缩判断过度复用。** 增加模型隔离和有效期检查；关闭功能、关闭缓存、缺少凭据或取消时不应用旧排除判断。重新判断失败会清除该交换的旧决策，保留原文。

不变的能力：近期消息、约束、错误、未完成工作、写操作不能被该交接删掉；原文可恢复；不确定测试仍运行；用户明确必选项始终保留；本地检查成功不替代 Codex 最终验收。交接不会改写 Codex 原生历史。

## 真实 Jev 小规模验证

合成场景：12 个工具都被明确指定为必用。先运行旧版，再运行新版；同一任务、同一工作区、生产 SQLite 预算，未修改或清空预算。关闭响应缓存以免用缓存命中冒充请求消除。仅一次付费请求，无重试。

| 指标 | 旧版 | 新版 |
|---|---:|---:|
| 函数耗时 | 661.17 ms | 0.24 ms |
| 实际 Jev 请求 | 1 | 0 |
| Jev 问题数 | 12 | 0 |
| Jev 输入 token | 1,653 | 0 |
| Jev 输出 token | 437 | 0 |
| 保留必用工具 | 12/12 | 12/12 |
| 功能验收 | 通过 | 通过 |

旧版实际响应模型为 `jev-1.13.0`，用量字段完整。本例消除了 **2,090 个不必要的 Jev token**。这是“已经明确必用”的确定性场景，不能外推到全部任务；没有测账户扣费。计时只覆盖函数，不含 Codex 计划、工具调度与最终回答。本轮开发本身的 GPT/后台判档消耗不在这个组件对照内。

真实对照开始时，本任务正常预算只剩约 2.55 秒等待额度，因此没有强行追加高并发付费实验，也没有开新作用域绕过预算。其余性能检查为下面明确标注的离线实验。

## 离线机制对照，不能作为真实提速宣传

固定每个模拟请求等待 40 ms，每个场景 3 组配对，交替先后顺序。总计 24 次组件运行，全部通过预设验收。模拟响应不填充虚构 token，用量值为 `null`。

| 场景 | 旧 → 新请求数 | 旧 → 新问题数 | 旧 → 新请求字节 | 旧 → 新平均耗时 |
|---|---:|---:|---:|---:|
| 12 个必用工具 | 1 → 0 | 12 → 0 | 4,029 → 0 | 43.71 → 0.15 ms |
| 1 项改动、9 个必测、3 个可选测试 | 2 → 2 | 13 → 4 | 4,760 → 1,777 | 86.02 → 43.00 ms |
| 内容规则与翻译 | 2 → 2 | 2 → 2 | 1,056 → 1,056 | 85.64 → 42.70 ms |
| 同一交换前插消息，连续交接 5 次 | 5 → 1 | 5 → 1 | 5,645 → 1,105 | 214.11 → 44.32 ms |

请求字节不是 token。并行减少的是独立等待，不减少请求数，也不保证服务端计费减少；预算按累计请求等待管理，不因为重叠就放宽。位置复用仍受有效期、模型、目标、来源变更等约束。服务端实际延迟、答案质量和长会话端到端效果还需更多生产样本。
