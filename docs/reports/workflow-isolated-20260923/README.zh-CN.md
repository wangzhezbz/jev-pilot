# 因插件安装失败而终止的隔离试验

2026-09-23。原计划 12 次：已完成 2 次真实 GPT 控制任务，Jev 组在推理之前安装失败，按停止规则终止。没有可用于评价 Jev 效果的配对。

- 原生组通过质量验收，170.670 秒，160,549 GPT token；出现两次原生重连通知。
- 空载适配层组通过质量验收，108.343 秒，164,549 GPT token。
- 完整组 `PLUGIN_INSTALL_FAILED`，没有启动模型任务。随后的无模型诊断复现了原生安装器 `File name too long` 错误。

原因：本地个人市场入口指向工作目录；实验又把 CODEX_HOME 放入仓库的 dist 子目录。安装器复制整个目录，发生目录递归嵌套。修复为发布文件白名单暂存目录，并把实验原生配置目录移到仓库外。不能把这两次控制任务的时间差归因于 Jev。

本目录保留冻结协议、用量和失败；native-wire-audit.json 是另一次不收费的原生请求检查，与真实任务效果无关。缓存检查仅证明请求前缀保持一致，不证明服务端缓存命中率。
