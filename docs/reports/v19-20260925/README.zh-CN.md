## 修改及质量保护

1. 可逆日志表示：完全相同的数字字段保留在模板；严格等差数列、周期序列和重复列用精确规则表示，异常保留。整数采用 BigInt，保留前导零与换行，返回前完整展开逐字比对；不符合或不够划算的文本原样返回。无语义排除，无额外 Jev 调用，原始文本仍可召回。事故日志表示从前一候选 15285 字节降到 6404 字节；这只是体积指标。
2. 只对已连续两次维持用户基准强度的有效判断，复用最多五个工具边界。自动降档不延长；失败、新阶段、新输入、手动改档和到期中断复用。实测判档仍每次 3 次，不能声称只判一次或零开销。
3. 费用报告逐代列出非缓存输入、缓存输入、输出、费用组成和缓存清零；安装校验新增两个投影模块的指纹。

363 项回归通过；27 项原生引擎与合成端点检查通过，包括 Astra/Sol/Luna 和 5.6 系列、缓存前缀、切档、手动设置及失败恢复。合成端点不证明真实服务缓存命中率。代码未改 Chrome/Computer Use，这轮没有新的浏览器性能结论。

这轮使用新的两对原生对照，不是与旧插件直接配对的增量因果实验。来源代码与测试候选一致，见 source-verification.json。此前费用/速度负面记录保留在 [上一轮](../cache-cost-20260925/README.zh-CN.md) 和 [更早单份输出实验](../optimization-20260925/README.zh-CN.md)。本轮仅证明该事故日志用例的观察结果，不推广成所有任务或平台的节省率。
