# Chrome 多语言与无损交接改进 · 2026-09-25

本轮实现三项局部修复，并单独运行新的原生任务对照。功能验证、组件体积和整任务收益分开记录；没有改变主模型、判档门槛或共享配额。

## 修复

1. Chrome/Computer Use 的正向允许列表可按同一操作绑定经 Codex 核对的语言等价名称。禁止项和风险检查沿所有等价名称生效；同时出现两个等价按钮则排除，未知名称仍交回 Codex。不是任意机器翻译后的自动授权。
2. 页面完成条件允许有限的字面语言备选项，每项业务要求仍必须成立，回执保留真实匹配的文本。阶段标志使用页面标题，避免把入口按钮误当成已经到达目标页。
3. 翻译在 Jev 判断期间改变页面时，旧票据作废，最多在原有预算内重新判断一次；再次变化或任何执行不确定都接手，绝不执行旧票据或盲目重试点击。
4. 上下文交接对未被语义排除的旧只读工具结果复用现有无损表示。每处出现、原始顺序和原文召回均保留；用户要求、近期和受保护内容保持字面形式。包括说明开销后收益不足时保留原文；不改写 Codex 原生历史。

## 真实 Chrome 验收

最初探针有一次过宽阶段标志造成的歧义接手，另一次页面翻译使票据过期。共 5 次 Jev 调用、3 次 Jev 操作、2 次接手，最终由 Codex 核验完成；这条失败记录保留在 chrome-probe.json。

修复后的英文页面：5 次 Jev 调用、5 次操作、0 次接手，局部循环 2.644 秒。中文控件的新记录：5 次调用、5 次操作、0 次接手，局部循环 2.704 秒。两次都通过独立最终页面核验；共输入 9,293 / 输出 530 Jev token。第一次探针的 4,464 / 265 token 另列，不从总成本中抹去。

以上是本机真实 Chrome 扩展与官方 cua_repl 执行，不是 headless 模拟。成功英文运行未观察到中途翻译，因此单次刷新逻辑的持续变化/票据废弃由离线回归验证；不能宣称覆盖所有自动翻译时序、语言和网站。中文页面是明确提供中文标签的合成页面，不是强制修改浏览器翻译设置。局部循环不含 GPT 规划和最终回答，无新 Chrome GPT token/费用/完整任务加速比例。本轮没有新增 Computer Use 实机数据。
