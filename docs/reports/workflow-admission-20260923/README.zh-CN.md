# 作废的全局环境对照：保留消费与失败证据

2026-09-23。已完成 3 次真实 GPT 任务，另 1 次被中止。**不能用于计算 JevPilot 的省时或省 token 效果。**

原生运行时并未按命令行覆盖彻底卸载全局插件。完整组 MCP 清单同时出现 `jev-pilot` 和 `jev_workflow` 两个 Jev 工具入口，以及其他全局插件。原生对照组因此不是已验证的无插件控制组；全局 MCP 的调用也可能不在实验私有数据库中。

发现后向本轮实验自己的 runner 发送 SIGTERM 以停止模型后端，随后结束 runner，保留 3 次已完成记录与第 4 次已开始记录。已完成 GPT 用量可见 CSV；被中断任务的 GPT 用量未知，不能当作零。后续实验使用私有 CODEX_HOME，并在每次付费推理前核对 MCP 清单。

`protocol.json` 是发现污染之前冻结的原计划，其中“全局插件禁用”的假设被现场证据推翻。`runs.json`/`runs.csv` 保留完成任务的观测，`interrupted.json` 保留已知中断调用。任何较快/较慢的差值均不应被引用为产品效果。
