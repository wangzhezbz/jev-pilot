# 完整任务 A/B：v18 更快，但本轮费用仍增加

测试日期：2026-09-25。**8 次任务全部通过独立验收；JevPilot 组任务耗时减少 12.47%，计入 Jev 的 API 等价估算费用增加 14.33%。当前版本没有通过“同时省时、省钱”的本轮验收。**

这是当前已安装版本 `0.2.0+codex.20260925123757`、`effort-v18-baseline-spacing` 的完整任务测试。不是只测筛选速度，也不是跨轮选取最好样本。

## 方法

固定 GPT-6 Sol、初始 high，同一原生 Codex `0.155.0-alpha.16.4`。两类任务，各两次重复、裸 Codex/完整 JevPilot 两组，共 8 次，单并发；每类任务第二次交换执行顺序。插件组保留路由、自动化、MCP 和通常说明，任务提示不强制 Jev、不强制完整读取。源码哈希、输入提示与文件哈希见 [protocol.json](protocol.json)。这是已使用过的合成任务回归，非盲测、非新任务泛化证明。

- 跨文件修复：租户隔离、复合键冲突、pending Promise 身份、成功/拒绝后的清理、同步异常与重试、零/负金额和币种；独立隐藏运行断言验收，并保留原 SPEC 和 smoke 测试。
- 日志排障：540 行日志，8 处散布事实；支持的根因、被否定的 DNS 假设、12/80 失败、修复与恢复、结算影响未知，全部引用原始行 ID。

## 实际生效情况和原因

1. **真实切档正常工作。** 共 20 次真实 Jev 判档、3 次改变建议，3 次全部收到原生 `applied`；无判档失败、无未知用量、无预算拦下改变。不存在“建议了却一次不改”的旧问题。但某一对恰好更快，不能单独因果归因为切档；没有改档的第一对修复也更快。
2. **证据筛选没有被选中。** 4 次插件任务的证据操作均为 0；两次日志任务仍先 `cat incident.log`，随后再用 `rg` 去除常规行。现有工具说明并不保证模型自然使用工具。自动调查提示还缺少 Analyze/分析触发词，并要求至少 8 个文件，单一大日志因此不符合条件。源码检查与这次轨迹共同定位了这个入口缺口。
3. **嵌套输出 hook 仍不能代替显式准备。** 31 次 `nested_native_result` 保守跳过，未对实际到达模型的外层结果做虚假“压缩”声明。这类读取一旦发生，整份文本已经进入后续上下文。此次没有自动输出过滤提交。
4. **GPT 往返次数和缓存差异主导费用。** 插件组 33 次生成，裸组 29 次；非缓存输入多 38,696 token。第一对修复有一条新回归测试断言过严，模型修正后重跑，全部返工计入。第一、第二对日志分别多 1 和 2 次 GPT 生成。[token-decomposition.csv](token-decomposition.csv) 将总差额恒等分解为额外轮次、首轮上下文差异、历史增长和输出差异；该分解不是随机化的模块因果贡献。
5. **Jev 本身不是本轮费用增加的主要部分。** 20 次请求输入 32,972 token，估算仅 $0.001384824，约占插件总估算费用 0.29%；GPT 费用从 $0.4116648 增至 $0.4692668。请求耗时合计 6.353 秒已包含在任务墙钟时间内，不能再次加到总时间。不能把其余时间全归为模型推理，服务等待也在其中。

## 修正与验证安排

完成这 8 次后才修改产品：为明确提到的 16–100 kB 单个 `.md` / `.txt` / `.log` 文件提供短提示，优先使用足够的原生检索，复杂筛选再调用 Jev。只读元数据，零模型调用；不改变命令、原文、权限和完整证据回读。原有多文件提示、关闭开关和 MCP 可用性门槛保持。

后续四次日志任务是独立、预先冻结的修正后样本，见 [修正后报告](../whole-task-text-hint-20260925/README.zh-CN.md)。不以修正后结果替换这里的旧结果，也不把两轮直接差值当作随机化因果效果。

## 费用和测量边界

费用按 2026-09-25 核对的 [OpenAI 官方价格](https://developers.openai.com/api/docs/pricing) 和 [TypeSafe 官方价格](https://docs.typesafe.ai/models) 估算：Sol 每百万非缓存输入 $2、缓存输入 $0.20、输出 $10；Jev 输入 $0.042、输出免费。逐次原生 token 通知核对增量与累计，重复通知去重；推理 token 已含于输出。原生缓存写入均报告为 0。Standard 费率作为比较假设，Fast 敏感性数据也保留在 [costs.json](costs.json)。未读取订阅账单，无法据此声称额度实际扣减相同百分比。

计时为同一桌面原生后端 `turn/start` 至 `turn/completed`，包括工具、失败返工和 Jev。隔离环境准备、插件安装与 MCP 就绪单列，不当作桌面每条消息固定发生的消耗。主对话的开发、测试编排与报告写作不属于这 8 项任务。未重新测 Chrome/Computer Use；此结论不覆盖它们。样本小且已知，没有稳定收益或质量泛化结论。
