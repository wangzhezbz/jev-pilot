# 按总成本和总耗时优化：2026-09-24

验收目标是**同等任务质量下，GPT 与 Jev 合计成本更低，整项任务用时更短**。总 token 上升本身不是失败；用廉价 Jev 输入替代昂贵 GPT 工作可以合理增加总 token。当前尚未证明普通桌面任务稳定达到这两个目标。

本轮实际完成了代码修复、266 项本地回归、27 项原版引擎合成验收、8 次独立 Jev 组件请求，以及两阶段共 11 次真实 GPT 任务尝试。10 次任务完成并通过独立答案检查，1 次因账户额度限制中断。按停止规则终止，未重试、未替换失败样本，后续第 4 次任务没有启动。

## 逐项问题与处理

| 问题 | 处理与证据 | 当前边界 |
|---|---|---|
| 1. 用总 token 代替成本 | 新增逐次生成的成本计算，拆开 GPT 未缓存输入、缓存输入、输出与 Jev 输入；推理输出不重复计费；输出标准/快速两种价格情景 | API 等价估算不是订阅额度实扣 |
| 2. 每次 Jev 重建连接 | 本次安装包含上一轮已验证的 keep-alive 连接池；不重复发送失败 POST | 六次小请求曾观察到暖连接均值低 54.37%，不是整项提速 |
| 3. 全批缓存稍有变化就失效 | 独立证据按单条完整输入、目标、规则、项目、模型缓存；重排复用，单项变化只付费判断该项 | 来源身份或原文件整体 hash 变化可能使更多项失效；宁可重新判断，不错用旧结论 |
| 4. 相关性判断共享大候选池 | 独立证据放入各自 question；共享 state 仅保留任务。与其他有共享语义的工作流分开 | TypeSafe 的 state 每请求只计一次，不能把原成本夸大成每问题重复计费 |
| 5. 不必调用模型的重复文本仍发给 Jev | 大文本 prepare 新增可逆原句字典：保留每次出现、所有来源、原顺序和原文恢复；有足够净收益才采用 | 不删语义、不做模糊去重；精确输出、代码、结构化结果和禁用状态仍绕过 |
| 6. 工具说明本身增加每轮输入 | 保留同一 schema 能力、限制和恢复约定，描述 JSON 由 3,773 缩至 2,926 字节，低 22.45% | 字节变化不是实测 token 变化；说明仍会占上下文 |
| 7. 筛选失败后又整段重读 | 保留原文回退，先尝试本地无损路径，减少可避免的付费筛选与失败机会 | 非重复语义文本的超时仍可能导致回退，不隐藏这笔成本 |
| 8. 调档频繁却保留原档 | 保留原来的租期、工具批次合并、调用上限及紧急复查；本轮没有强行降低复杂任务档位 | 首组 17 次路由判断仅 3 次降低档位；路由收益尚未证明，不能靠牺牲功能掩盖 |
| 9. 重试重复收费 | 连接池保留零自动 POST 重试，取消和总截止有效；原先有界恢复不扩大 | 请求超时可能已收费，缺 usage 时标为未知，不能当成 0 |
| 10. 缓存归因过粗 | 每次有效原生 usage 新增 generation_usage；成本对账验证累计增量、重复通知、reasoning 子集 | 记录主机观测时间，不冒充纯推理耗时；不同任务首步缓存仍可能不平衡 |
| 11. 源码修好了、安装还是旧版 | 明确检查旧活动进程，安装经过验收的插件及后台适配层，核对版本和文件指纹 | 安装成功与旧进程已加载是两个状态，见安装回执 |
| 12. 功能和收益混为一谈 | 固定独立答案、AB/BA 顺序、所有请求及失败记录；成本、时间、质量分别公布 | Windows/Linux CI 不等于真实桌面验收；小样本不是普遍收益证明 |

没有自动换主模型，没有提高排除相关证据的门槛来凑收益，没有删除精确恢复、失败复查、手动档位、浏览器协作或其他已有能力。仍保留预算和原生执行回退。

## 真实组件结果：独立判断与缓存

预先固定顺序为共享池 / 独立项 / 独立项 / 共享池，再测试首次缓存、重排、修改一项。相同 12 个语义样本，禁止重试，总计 8 次真实 Jev 请求。旧共享池两轮均把同一条本应 review 的含糊请求判为 exclude；新独立项五轮均符合预设标签。该样本不能证明一般正确率。

| 输入情况 | 实际 API 次数 | 付费问题数 | 本地端到端 ms | 已知 Jev USD |
|---|---:|---:|---:|---:|
| 共享池首次 | 2 | 12 | 629.15 | 0.000477288 |
| 独立项首次 | 1 | 12 | 374.47 | 0.000468972 |
| 独立项重复、禁用缓存 | 1 | 12 | 338.63 | 0.000468972 |
| 共享池重复、禁用缓存 | 2 | 12 | 313.10 | 0.000477288 |
| 开启单项缓存，首次 | 1 | 12 | 365.67 | 0.000468972 |
| 仅重排 | **0** | **0** | **0.52** | **0** |
| 修改其中一项 | **1** | **1** | **288.57** | **0.000050988** |

两种输入布局单次已知费用只差约 1.74%，不宣称数量级下降。可确认的机制收益是重排不调用、修改一项只重判一项。全部组件调用已知费用合计 $0.00241248。原始请求回执及答案：[independent-judgments.json](independent-judgments.json)。

新增无损路径的离线生产函数验收：180 条资料，原文 58,616 字节 → 展示 32,255 字节，低 **44.97%**；操作约 **4.49 ms**，0 次模型调用；所有记录逐条展开完全一致，完整原文恢复完全一致。这是本地展示实验，不是模型已接收或整项提速证明。[原始数据](projection-component.json)

## 第一阶段：完整 8 次正常入口对照

GPT-6 Astra，起始 high；2 类任务 × 2 次重复 × 原生/插件组；每任务 AB/BA 顺序，单并发。无损 prepare 修复尚未包含在该冻结版本中。没有强制调用 Jev；工具选择由模型决定。独立检查包含正确案例集合、根因和数字、来源未修改等。所有 8 次通过。

## 计价口径与复现

2026-09-24 官方标准 API 价，每百万 token：GPT-6 Astra 未缓存输入 $10、缓存输入 $1、输出 $50；GPT-6 Sol $2 / $0.2 / $10；GPT-6 Luna $0.1 / $0.01 / $0.5；GPT-5.6 Sol $4 / $0.4 / $20。Jev 1.13.0 输入 $0.042，输出免费。价格来源：[OpenAI 价格](https://developers.openai.com/api/docs/pricing)、[Astra 模型](https://developers.openai.com/api/docs/models/gpt-6-astra)、[TypeSafe 模型](https://docs.typesafe.ai/models)。

成本脚本按单次请求处理长上下文倍率、缓存写入和快速层倍率；本次请求 cache-write 记录为 0。快速层价格情景对 GPT 乘 2，不对 Jev 乘 2。原生累计用量去重并逐步核对；路由 decision 是 Jev 调用的第二份视图，不重复收费。请求的服务层未观测，因此两种价格只是公开 API 等价情景，不是 ChatGPT 订阅实际扣款、额度、账单或节省金额。

本轮 11 次 GPT 尝试与 8 次独立 Jev 组件请求，标准价已知实验成本共约 **$4.90325**，加上两次 Jev 超时未知费用；包括失败任务。当前主任务对话消耗不在此实验账本。计入未完成任务后没有宣称整体获得净节省。

复现实现：`scripts/acceptance/independent-evidence-live.mjs`、`factorial-run.mjs`、`cost-analyze.mjs`。付费执行必须显式 `--run`，本次遇到账户上限后不再执行。原始本地记录留在 dist；公开数据移除机器路径与秘密。两个阶段分开保留源 hash、协议、版本、usage 和判定。
