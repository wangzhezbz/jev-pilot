# Chrome / Computer Use：真实操作与判断成本对照

2026-09-24。结论：**浏览器动作选择的 Jev 成本已降低；尚未证明完整 Codex 桌面任务稳定提速或节省 GPT 费用。Chrome 扩展性能验收仍被通信故障阻塞。**

## 这次实际改了什么

- 浏览器一步只需选一个动作，旧实现却独立分类每个候选。本轮改成单个互斥 Choice，并保留 `review` 出口。完整候选元数据仍传入，避免省略用于区分目标的字段。若总内容超过单题限制，自动回到原有分批判断；40 个长候选的回归通过，避免优化导致原能力丢失。
- 显式危险动作、需要授权的动作、相同观察下已选过的动作在本地排除。全部不可选时不再支付一次无效 API 调用。
- 保留 30 秒观察期限、相同页面核验、单次票据、旧票据失效、驱动匹配、步数上限及独立结果验收。失败不会自动重试或冒充 Jev 成功。
- 更新已过时的官方驱动入口说明；原文仍指向已退役的 `cua.listBrowsers()`。当前 Chrome 和 macOS Computer Use 按各自官方 skill 使用。

依据 [TypeSafe Choice](https://docs.typesafe.ai/primitives/choice) 的互斥选择语义与 [API](https://docs.typesafe.ai/api) 实施。没有为减少模型调用而移除执行前后的状态检查。

## 为什么仍然没有明显变快

| 平均每任务耗时 | 旧实现 | 新实现 |
|---|---:|---:|
| 常规观察及最终验收 | 1,023 ms | 954 ms |
| Jev 决策及本地请求往返 | 673 ms | 575 ms |
| 执行前重新观察 | 142 ms | 141 ms |
| 票据消费 | 4 ms | 5 ms |
| 两次 UI 点击 | 1,241 ms | 1,243 ms |

新实现减少了决策开销，但 UI 点击、等待和观察仍约占总时间的 80%。Jev 无法直接消除这些宿主开销。仅压缩 Jev 问题数量，也不会消除 GPT 在每个工具边界的重新推理。

作为诊断下界，另跑两次**已经写好动作的固定脚本**，同样点击并读取结果，平均 2.003 秒，无 Jev。它不是通用代理：事先知道每一步该点什么，也不经过 Jev 票据链。因此只能说明“已知动作再插入判断会增加开销”，不能称为 GPT 原生组或宣称 Jev 比 GPT 更慢。

当前应采用的行为：明确且已知的机械步骤直接用宿主工具；需要语义选择时用 Jev；在宿主允许的同一工具调用内串接有边界的观察、选择、核验、执行，减少 GPT 中间轮次。每步仍必须读取最新界面；未知控件、权限要求或不确定结果交回 Codex。

**这一轮没有执行独立的完整 GPT 浏览器任务 A/B，也没有得到相应 GPT token。** 上轮付费任务已遇到账户配额错误，本轮没有重试该付费入口。不能把本报告的 Jev token、脚本用时或少显示的界面文字换算成 GPT 节省。

## 保留失败和反向结果

预实验使用只传候选文字及目标的版本。8 个 Jev 协作任务均完成，但新实现平均 2.984 秒，旧实现 2.892 秒，**反而慢 3.16%**；输入 token 少 31.11%。代码复核发现这种缩减可能丢失真实任务需要的候选元数据，于是恢复完整候选信息并重跑正式组。两组均保留，不能只挑正式组的省时数字做宣传。

预实验还有两条失败记录：

1. 首次固定脚本完成两次点击后，页面被 Chrome 自动翻译，精确英文验收器拒绝结果。只给测试页加 `translate=no` 和 `notranslate` 标记；未更改用户全局翻译设置。后续刷新并重新观察。
2. 一次旧实现任务在准备阶段遇到 Computer Use 原生通道断开。尚未调用 Jev；没有把它按零耗时成功任务计入。重新读取官方驱动状态恢复后，另起一条记录继续。

两批合计：20 次完成的 UI 流程，2 条失败记录；32 次真实 Jev 请求，输入 25,924、输出 2,840 token，已知估算费用 **$0.001088808**，没有未知用量的 Jev 请求。这不包括当前 Codex 会话自身费用或上一轮其他实验费用。

## Chrome 扩展阻塞

官方浏览器发现成功；Chrome 进程、扩展已安装启用、native-host manifest 检查均通过。但会话命名和独立的轻量标签页读取均超时。故障发生在任务执行前，尚不能定位为 VPN、Jev 或页面加载问题。

按官方排障文档，下一步需用户允许打开检测到的配置窗口再连接一次。未修改 Chrome/插件权限、VPN、官方二进制或原生通信配置。**Chrome 扩展本轮没有成功的任务执行，没有性能或 token 对照结果。**
