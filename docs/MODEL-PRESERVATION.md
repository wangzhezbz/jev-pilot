# 主模型保持与按需委派

JevPilot 默认保留用户选择的 Codex 主模型。自动路由只选择该模型支持的推理强度和复查周期，不选择另一个 GPT 模型；用户主动换模型仍由 Codex 处理。

当前没有启用自动跨模型切换。兼容多个模型，指各模型都可使用推理强度适配，并不表示任务会在它们之间自动转移。

复杂分析、实现和最终交付由用户选择的主模型负责。Jev 用于有明确候选和依据的判断或证据筛选；代码处理精确计算与确定性规则。没有足够依据时保留材料或回读原文，不能把 Jev 的判断当作执行授权或完成证明。

六个模型入口的回归检查验证：即使判断返回额外的其他模型字段，自动设置请求也只有任务标识和 effort；降档及恢复不会写入 model。这个协议检查不代表降低 effort 对任意任务都没有质量影响。

自动换模型暂不作为默认优化路线。将来如有实验功能，需要用户明确选择加入，并分别验证任务质量、返工后的总耗时、完整用量和缓存影响；不能凭单次便宜或切换成功推广。

当前收益验证分开处理：相同插件入口下固定 high / 固定 medium / 自动判档，测路由的增量；固定主模型下全文 / Jev 预选证据，测委派机制。后者不能替代普通桌面对话的自动触发验收。
