# JevPilot

**Jev プラグインをひとつ。Codex の使い方はいつもどおり。**

JevPilot は、推論強度の選択、必要なコンテキストの選別、失敗した手順からの復旧支援を、ひとつの Codex プラグインにまとめるプロジェクトです。一度インストールして TypeSafe アカウントを接続すれば、同じ会話の中でそのまま作業を続けられることを目指しています。

**現在は開発初期段階です。** このリポジトリには、プロジェクトの概要とロードマップが含まれています。公開インストーラーや実行可能なプラグインはまだありません。以下は実装を予定している機能です。

<a id="workflow"></a>

## 仕組み

ユーザーがタスクを伝え、Codex が計画、実装、最終確認を担当します。Jev はその途中で、範囲を限定した細かな判断を引き受けます。

<p align="center"><img src="assets/workflow.ja.svg" width="100%" alt="予定している流れ：ユーザーは普段どおり Codex に依頼し、Codex が計画・実装・検証を担当。JevPilot が推論強度の選択、コンテキストの選別、失敗原因の分類を支援します。" /></p>

たとえばバグの調査では、JevPilot が関連する検索結果やログの箇所を選び、一時的なネットワーク障害とコードの問題を切り分ける支援を想定しています。根拠を読み、修正し、結果を検証する役割は引き続き Codex が担います。

<a id="capabilities"></a>

## 予定している機能

| 機能 | 目的 |
| :--- | :--- |
| **推論強度の自動調整** | 現在の手順に合う強度を選び、実行環境に実際に適用されたかを記録します。 |
| **関連コンテキストの選別** | 検索結果や候補ファイルに優先順位を付けてから詳しく読みます。 |
| **原文を保持するフィルタリング** | 長いツール出力を絞り込み、必要になれば元の内容を読み直せるようにします。 |
| **失敗からの復旧支援** | 失敗の種類を判別し、効果のない操作の繰り返しを減らします。 |
| **完了の根拠確認** | 完了報告を、タスクに必要なチェックとその実行結果に照らして確認します。 |
| **ブラウザー操作の支援** | 範囲を限定した操作を実行し、検証のために Codex へ制御を戻します。 |
| **実際の動作と効果の表示** | Jev の実呼び出し、適用された変更、遅延、取得可能なトークン使用量を表示します。 |

これらのモジュールは、ひとつのインストール経路を通じて段階的に提供する予定です。複数のスキルを管理したり、タスクごとに特別な呼び出し文句を覚えたりする必要がない設計を目指します。

## 対応予定のプラットフォームとダウンロード

| 対象プラットフォーム | 公開パッケージ | 対応状況 |
| :--- | :--- | :--- |
| Windows | 未公開 | 計画段階・未検証 |
| macOS | 未公開 | 計画段階・未検証 |
| Linux | 未公開 | 計画段階・未検証 |

3 つのプラットフォームへの対応を目標にしています。実際の互換性は、OS、Codex クライアント、バージョンごとに検証して公開します。上部のカードは、すべての OS でデスクトップクライアントが利用可能であることを示すものではありません。検証済みパッケージを公開するまでは、このセクションへ移動します。

ビルドの準備が整い次第、ダウンロードと検証済みの互換性情報を [Releases](https://github.com/wangzhezbz/jev-pilot/releases) に掲載します。現時点で実行するインストールコマンドはありません。

## 効果の測定

- **時間：** 振り分け処理や再試行を含む、タスク全体の所要時間。
- **使用量：** 取得可能な入力、キャッシュ入力、出力、推論トークン数。Jev の使用量は別に記録します。
- **品質：** タスクの受け入れ条件の達成、根拠の見落とし、原文の再取得、手戻り。
- **実際の動作：** 推奨された設定と、実行環境で適用を確認できた変更を分けて記録します。

推論強度を下げたりツール出力を短くしたりするだけでは、タスクの高速化やアカウント使用量の削減を証明できません。すべてのタスクに共通する削減率を約束するのではなく、対象タスクと測定方法を添えて結果を公開します。

## 開発

最初の段階では、共通コア、プラットフォーム別アダプター、統一された設定手順、診断機能、通常の Codex 動作に戻れる仕組みを整えます。その後、検索結果の選別と失敗からの復旧支援、続いてブラウザー操作の支援を追加する予定です。

[マイルストーンと受け入れ条件](docs/ROADMAP.md)は英語・中国語で掲載しています。試したい具体的な作業があれば、タスク、OS、Codex のバージョンを添えて [Issue](https://github.com/wangzhezbz/jev-pilot/issues/new) を作成してください。API キーや非公開のログは記載しないでください。
