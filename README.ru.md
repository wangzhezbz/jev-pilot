# JevPilot

**Один плагин для привычной работы в Codex.**

Рабочая предварительная версия: 14 модулей используют общий MCP, один автоматически вызываемый навык и настольный адаптер. Codex планирует, реализует и проверяет; Jev принимает ограниченные решения.

## Все 14 функций

| # | Возможность | Назначение |
| :--- | :--- | :--- |
| 1 | **Автоматические решения** | Пакетный выбор из заданных вариантов, кэш и возврат к Codex при сбое. |
| 2 | **Интенсивность рассуждений** | Изменение параметра реального запроса с сохранением модели и подтверждением применения. |
| 3 | **Поиск и отбор файлов** | Ранжирование фрагментов со ссылками на источники и указанием пропусков. |
| 4 | **Обратимая фильтрация** | Полезные части длинного вывода с сохранением полного оригинала. |
| 5 | **Выбор инструментов** | Отбор подходящих инструментов с сохранением обязательных и спорных кандидатов. |
| 6 | **Восстановление после сбоев** | Разбор наблюдаемых ошибок без бесконечных повторов. |
| 7 | **Проверка результата и качества** | Фактические результаты команд, актуальность источников, правила и переводы. |
| 8 | **Chrome и Computer Use** | Существующие плагины, свежие наблюдения, одноразовые разрешения на шаг и проверка результата. |
| 9 | **Память проекта** | По согласию пользователя: источники, срок действия, конфликты и отзыв. |
| 10 | **Фактическая статистика** | Отдельный учёт Jev, данных среды выполнения и применённых изменений. |
| 11 | **Сжатие для передачи контекста** | Восстановимая передача с сохранением ограничений и незавершённых задач. |
| 12 | **Анализ изменений и тесты** | Приоритизация проверок без исключения обязательных тестов. |
| 13 | **Контрольные точки** | Сохранение прогресса с проверкой изменений файлов перед продолжением. |
| 14 | **Точное извлечение** | Исходные фрагменты и позиции; явное указание отсутствующих и неоднозначных полей. |

## Платформы и использование

Для этой версии нужны Node 24+, curl и rg. Установите один плагин, настройте личный ключ TypeSafe локально и поручите настройку Codex. Для обычных задач не нужны отдельный запуск или специальные фразы. См. [руководство](docs/FEATURES.md).

Переносимые тесты прошли на macOS, Windows и Linux. Проверены реальная среда Codex на macOS и Computer Use. Настольные сеансы Windows/Linux требуют проверки на устройствах. Реальное расширение Chrome прошло выбор действия Jev, однократное выполнение и проверку страницы при выключенном TUN. Исправление наследования прокси затрагивает только конфигурацию плагина, не файлы Codex. Подписанных публичных установщиков пока нет.

## Проверка и ограничения

Сжатая передача контекста не изменяет историю Codex и не возвращает уже потраченные токены. Универсальная экономия времени, токенов или лимитов не заявляется. См. [отчёт](docs/reports/ACCEPTANCE.md), [границы функций](docs/FEATURES.md) и [план](docs/ROADMAP.md).

Новые измерения: [отчёт от 23 сентября 2026 года](docs/reports/validation-20260923/README.md) содержит реальные вызовы, ошибки, токены и время каждого запуска, а также воспроизводимые примеры. Сокращение вывода инструмента не обязательно снижает расход всей задачи.

JevPilot распространяется по лицензии [MIT](LICENSE). Независимый проект, не официальный продукт OpenAI или TypeSafe.

Проверка полного процесса: [исследование и результаты v14 (на китайском)](docs/reports/workflow-clean-20260923/README.zh-CN.md). Исправлена установка, добавлена пауза после повторных решений без изменения режима. Общее ускорение и экономия токенов пока не подтверждены.
